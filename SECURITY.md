# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately, either

* through GitHub: **Security → Report a vulnerability** on this repository, or
* by e-mail to **contact@xevorislabs.com** with the subject "Security".

Include what you found, where (file and version, or document), how to
reproduce it and what an attacker could do with it. We reply within 7 days, keep you informed, and credit you when the
fix is published unless you prefer to stay anonymous.

## Scope

* Flaws in the model or the architecture that let an insider evade detection, frame a colleague or cause innocent
  employees to be restricted.
* Vulnerabilities in the engine, the log adapters, the HTTP service or the Docker image.
* Personal or confidential data accidentally published in this repository.

Results from public datasets are pseudonymised; if you find an identity that was missed, please report it.

## Supported versions

Only the latest version (currently v0.9) receives fixes. This is a research prototype and not intended for
production use yet.
